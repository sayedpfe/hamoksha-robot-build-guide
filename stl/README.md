# Print files

Ready-to-print STL files for the parts designed for Hamoksha, grouped by area. Print settings and measuring notes are in the phase pages.

Contents:

- Phase 1 (door opener): clamp_cap, clamp_cradle, control_board, magnet_L_bracket, magnet_actuator_foot, microswitch_holder, p1_motor_box
- Camera and screen: monitor_cam_clip, Gimbal_mesh_all_d435 (from XLeRobot)
- `base/`: wheel_adapter, wheel_bracket_right
- `body/`: screen frame and back pieces, head pieces
- `lift/`: electronics_box_tray

Parts derived from the XLeRobot project keep their credit and license: see the README acknowledgments.
